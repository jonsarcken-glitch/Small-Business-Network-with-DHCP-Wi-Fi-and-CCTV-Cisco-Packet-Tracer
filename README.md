# Small-Business-Network-with-DHCP-Wi-Fi-and-CCTV-Cisco-Packet-Tracer
This project demonstrates the design of a small business network using Cisco Packet Tracer. The topology integrates wired and wireless connectivity, centralized DHCP services, and connected camera devices to simulate a basic business IT infrastructure.

Project Objectives
Design a practical small business network topology.
Automate IP address assignment for client devices through DHCP.
Integrate wired devices with a wireless network.
Provide wireless connectivity for owner and guest/customer devices.
Incorporate connected camera devices into the network design.
Practice basic network configuration and connectivity troubleshooting.

Tools and Technologies
Cisco Packet Tracer
Cisco IOS CLI
Cisco 2911 Router
Cisco 2960 Switch
HomeRouter-PT-AC
DHCP, IPv4, Ethernet, Wi-Fi, and IoT device connectivity

Learning Outcomes
This project helped me practice small business network design, DHCP configuration, wired and wireless network integration, IP addressing, and connected-device networking.

Project status: Topology designed in Cisco Packet Tracer. DHCP lease allocation, wireless client connectivity, device reachability, and camera functionality should be validated and documented separately before claiming full end-to-end operation.
